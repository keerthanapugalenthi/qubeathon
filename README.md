# BIS VerifyLens

**Qubeathon PS01 Project**

## Overview
**BIS VerifyLens** is an automated verification and compliance analysis tool designed for the Bureau of Indian Standards (BIS) ecosystem. It streamlines the validation of product standard compliance, certification marks, and license details.

## Tech Stack (Planned)
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS / Modern UI components
- **Verification Engine:** Automated verification workflows and APIs
